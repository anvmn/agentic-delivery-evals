When a code reviewer errs, which way does it fall?

Ten models blind-review two files: one correct (String.toList), one genuinely buggy (String.length). Bars left = the reviewer invented a bug in the correct file. Bars right = it missed the real bug. No bars = judged both correctly every trial. The field leans hard left — hallucinated rejections dominate — and Grok, marketed on non-hallucination, is the only model that leans right. Within Moonshot: K2.7-code hallucinates 4/6, flagship K3 never — the error is a tier property, not a vendor property.
